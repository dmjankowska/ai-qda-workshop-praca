# Trwałe wyniki Vibe Coding

Każdy notebook zapisuje tutaj produkty z własnym prefiksem:

- `01_` - rejestr jednostek, karta procedury i decyzja o jednostce;
- `02_` - przypisania kodów opisowych i decyzje o promptach;
- `03_` - kandydackie kody zogniskowane oraz mapowanie kodów opisowych;
- `04_` - kandydacka książka kodowa i handoff do Codexa.

Kolejny notebook odczytuje produkty poprzedniego etapu z tego samego katalogu.
W publicznym wzorcu nie ma wyników uczestników. Po sprawdzeniu artefaktów
komórka `Zapisz trwały punkt kontrolny` może dodać wybrane pliki do prywatnego
repo uczestnika. Pliki `*_prompt_runs.jsonl` pozostają domyślnie poza commitem.
