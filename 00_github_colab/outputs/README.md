# Wyniki modułu wprowadzającego

Notebooki `00` i `01` zapisują tutaj sprawdzone produkty modułu zerowego:

- `00_procedure_card.csv` - pierwsza karta procedury;
- `01_prepared_evidence_units.csv` - jednostki z zachowanym śladem do źródła;
- `01_quality_report.csv` - wynik kontroli technicznych;
- `01_researcher_decisions.csv` - decyzje pozostawione badaczowi;
- `01_procedure_card.json` - kontrakt pierwszej małej procedury.

W publicznym wzorcu katalog zawiera tylko ten opis. W prywatnym repo
uczestnika notebook może dodać sprawdzone produkty przez osobną komórkę GitHub.
Sekrety nie są zapisywane. Pełne logi odpowiedzi API nie są domyślnie
commitowane.
