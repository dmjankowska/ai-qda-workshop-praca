# Legenda Relacji

Graf odróżnia relacje analityczne od hierarchii. Strzałkę czytaj jako zdanie:
`kod źródłowy -> predykat -> kod docelowy`, a następnie sprawdź warunki,
kontrdowód i status.

| Rodzina | Pytanie kontrolne | Przykładowe brzmienie |
| --- | --- | --- |
| `conditioning` | W jakich warunkach jedno zjawisko umożliwia, ogranicza lub zmienia drugie? | warunkuje, ogranicza wykorzystanie |
| `temporal` | Co poprzedza, następuje po czym albo tworzy sekwencję? | poprzedza, prowadzi później do |
| `processual` | Jak jeden proces przekształca się w drugi? | współtworzy, nasila |
| `strategic_response` | Jakie działanie jest odpowiedzią na sytuację lub mechanizm? | skłania do, uruchamia |
| `resource_distribution` | Jak zasób, koszt lub dostęp przepływa między aktorami? | przenosi koszt, odracza presję |
| `interactional` | Jak zjawiska są wytwarzane w interakcji? | wzmacnia w kontakcie, negocjuje |
| `structural` | Jak reguła lub układ instytucjonalny organizuje inne zjawisko? | ustanawia, uzależnia |
| `contrastive` | Jaki kontrast ujawnia granicę albo odmienny mechanizm? | konfliktuje z, różnicuje |
| `interpretive` | Jak jedno doświadczenie zmienia ocenę lub znaczenie drugiego? | czyni kryterium oceny |
| `variation` | Jak ten sam proces zmienia się między warunkami lub przypadkami? | przyjmuje wariant |

## Poziomy I Statusy

- `F-F` i `T-T` są domyślnym widokiem interpretacyjnym.
- `D-D` jest opcjonalnym poziomem szczegółowym; nie należy go generować w
  podstawowym ćwiczeniu.
- `grounded_candidate` ma wsparcie w więcej niż jednym niezależnym przypadku.
- `memo_hypothesis` jest użyteczną hipotezą, ale nie ustaleniem.
- `needs_review` wymaga powrotu do cytatów albo zmiany predykatu.
- `reject` pozostaje w audycie jako odrzucona propozycja, nie relacja wyniku.

Krawędź nie jest prawem przyczynowym. Jej siła zależy od dosłownych fragmentów,
liczby niezależnych przypadków, warunków zakresu i kontrdowodów.
